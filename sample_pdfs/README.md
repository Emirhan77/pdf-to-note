# Sample PDFs

Bu klasor, uygulamayi gercek PDF'lerle denemek icin indirilen ornekleri tutar. PDF dosyalari ucuncu taraf kaynaklardan geldigi icin `.gitignore` kapsamindadir.

## Indirilen dosyalar

- `btk_bulut_bilisim.pdf`: BTK, Bulut Bilisim.
- `subu_bulut_bilisim.pdf`: SUBU dokuman API uzerinden Bulut Bilisim PDF'i.
- `mit_ai_ch1_intro.pdf`: MIT OpenCourseWare 6.034 Artificial Intelligence, Chapter 1 Introduction.
- `mit_ai_ch4_learning.pdf`: MIT OpenCourseWare 6.034 Artificial Intelligence, Chapter 4 Learning Introduction.

## Hızlı deneme

1. `python app.py` ile uygulamayi baslat.
2. `http://127.0.0.1:5000` adresini ac.
3. PDF dosyasi secme alanindan bu klasordeki PDF'lerden birini yukle.
4. Not uzunlugu ve soru sayisini secip `Analiz Et` butonuna bas.
